# Disco logos

Shown beside each disco in the electricity form (WhatsApp Flow dropdown).
One PNG per disco, named by its short code, at most 60 KB (aim for ~96x96):

IKEDC.png  EKEDC.png  AEDC.png  KEDCO.png  PHED.png  JED.png  KAEDCO.png  EEDC.png  IBEDC.png

**Republish the Flow (pin_flow.json) before adding any logo here.** The
published Flow must declare `image`/`alt-text` on the disco items first, or
WhatsApp rejects the electricity screen's data.

A missing or oversized file just shows the name without a logo. Use logos you
have the right to use (from each disco's brand/partner kit).
